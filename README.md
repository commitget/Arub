# Personal Accounting App

A pet project for practicing and showcasing React/Python development skills through building a practical financial tracking application.

## Purpose
This project demonstrates proficiency in:
- React with TypeScript
- Component architecture and hooks
- State management
- Data visualization
- Responsive design

Built as a learning exercise to apply modern web development practices in a real-world scenario.
```
pip install python-dotenv
pip install flask
pip install flask_sqlalchemy
pip install flask_cors
```
